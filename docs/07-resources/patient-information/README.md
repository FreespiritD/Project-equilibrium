## In Crisis?

If you're in crisis or having thoughts of self-harm:

**Emergency Services**: 999
**NHS Crisis Line**: 111 (option 2)
**Samaritans**: 116 123 (24/7)
**Crisis Text**: Text SHOUT to 85258
**NHS 111**: For urgent medical help
