# Meta-Analyses for Project EQUILIBRIUM

## Purpose

This directory is reserved for specialized meta-analytic reviews that go beyond individual systematic reviews. While the [systematic-reviews/](../systematic-reviews/) directory contains comprehensive evidence reviews for specific interventions, this directory will house meta-analyses that:

1. **Pool data across intervention types** (e.g., all lifestyle interventions combined)
2. **Examine moderators and mediators** (what predicts response, how do interventions work)
3. **Conduct network meta-analyses** (comparing multiple treatments simultaneously)
4. **Perform individual patient data (IPD) meta-analyses** when available

## Current Status

**Status**: Directory structure created, content to be developed

The evidence base currently relies on published meta-analyses cited in the systematic reviews. As Project EQUILIBRIUM develops, this directory may include:

- **Custom meta-analyses** conducted by the EQUILIBRIUM research team
- **Updated meta-analyses** incorporating latest studies
- **Subgroup analyses** specific to UK populations or primary care settings
- **Network meta-analyses** comparing all available treatments simultaneously

## Planned Content

### 1. Lifestyle Interventions Combined

**Proposed**: Meta-analysis pooling exercise, diet, sleep, and stress management interventions
- **Purpose**: Overall effect size for lifestyle approach
- **Moderators**: Which interventions for which populations
- **Timeline**: Year 2-3

### 2. Primary Care-Delivered Interventions

**Proposed**: Meta-analysis of interventions deliverable in primary care settings
- **Purpose**: Establish feasibility and effectiveness in GP practices
- **Focus**: Brief interventions, practicality, scalability
- **Timeline**: Year 2

### 3. Long-Term Outcomes

**Proposed**: Meta-analysis focusing on ≥1 year outcomes
- **Purpose**: Comparative long-term effectiveness
- **Outcomes**: Relapse rates, sustained remission, quality of life
- **Timeline**: Year 3-4

### 4. Network Meta-Analysis

**Proposed**: Comparing all available treatments (medication, various psychotherapies, lifestyle interventions, combinations)
- **Purpose**: Rank treatments, identify optimal sequences
- **Methods**: Bayesian network meta-analysis
- **Timeline**: Year 4-5

### 5. Individual Patient Data Meta-Analysis

**Proposed**: If IPD available from trials
- **Purpose**: Identify treatment responders (precision medicine)
- **Predictors**: Baseline characteristics, symptom profiles, biomarkers
- **Timeline**: Year 5+, dependent on data sharing agreements

## Why Separate from Systematic Reviews?

**Systematic reviews** in this project focus on:
- Comprehensive narrative synthesis
- Clinical implementation guidance
- Practice recommendations
- Accessible to all stakeholders

**Meta-analyses** focus on:
- Statistical pooling and precision
- Moderator analyses
- Publication bias assessment
- Technical/research audience

## Quality Standards

Any meta-analyses added to this directory must meet:
- **PRISMA guidelines** for reporting
- **Pre-registration** (PROSPERO or equivalent)
- **Risk of bias assessment** (Cochrane RoB 2 or equivalent)
- **GRADE assessment** for certainty of evidence
- **Publication bias assessment** (funnel plots, Egger's test)
- **Sensitivity analyses** (leave-one-out, subgroups)
- **Peer review** (published or pre-print with planned publication)
