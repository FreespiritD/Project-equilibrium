# Evidence Tables

## Purpose

Structured evidence tables provide at-a-glance summaries of key studies supporting Project EQUILIBRIUM. These tables are essential for:
- Quick reference during presentations
- Grant applications
- Policy briefings
- Academic publications
- Training materials

## Planned Format

**File**: evidence-tables.xlsx (Microsoft Excel)

**Structure**: Multiple worksheets:

### Sheet 1: Exercise for Depression
- Study (Author, Year)
- Design (RCT, Meta-analysis, etc.)
- Sample Size
- Population
- Intervention
- Comparator
- Outcomes
- Effect Size (SMD or d)
- 95% CI
- Quality Rating (GRADE)
- Notes

### Sheet 2: Diet and Mental Health
- Same structure as above
- Focus: Mediterranean diet, omega-3, nutritional interventions

### Sheet 3: Mindfulness-Based Interventions
- MBSR, MBCT studies
- Anxiety and depression outcomes

### Sheet 4: Sleep Interventions
- CBT-I studies
- Sleep-depression bidirectional evidence

### Sheet 5: Psychotherapy Effectiveness
- CBT, BA, IPT, PST
- Comparative effectiveness

### Sheet 6: Comparative Effectiveness Summary
- Direct head-to-head trials
- Exercise vs. medication
- Psychotherapy vs. medication
- Integrated approaches

### Sheet 7: Prescribing Data
- UK trends
- International comparisons
- Inappropriate prescribing statistics

### Sheet 8: Economic Evidence
- Cost-effectiveness analyses
- Cost per QALY
- ROI calculations

## Using Evidence Tables (When Available)

### For Presentations

**Quick access** to key statistics:
- Effect sizes for each intervention
- Confidence intervals
- Quality ratings

**Example use**: "Exercise for depression: 25 RCTs, N=1,487, SMD=0.62 (95% CI: 0.42-0.82), Grade A evidence"

### For Grant Applications

**Systematic evidence** summary:
- Demonstrates rigorous evidence review
- Supports funding requests
- Shows intervention effectiveness

### For Policy Briefs

**Concise data** for decision-makers:
- Effect sizes translated to clinical impact
- Cost-effectiveness data
- International comparisons

### For Academic Publications

**Supplement** to manuscripts:
- Can be uploaded as supplementary material
- Enables replication and verification
- Demonstrates transparency

## Quality Assurance

When created, evidence tables will:
- ✓ Include only peer-reviewed studies
- ✓ Use standardized effect size metrics (SMD, d, RR, OR)
- ✓ Report 95% confidence intervals
- ✓ Include GRADE quality ratings
- ✓ Note limitations and caveats
- ✓ Be regularly updated (annually)
