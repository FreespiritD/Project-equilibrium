# Documentation

This directory contains comprehensive documentation for Project Equilibrium, organized by topic area.

## Structure

- **00-executive-summary/**: High-level project overview, key findings, and recommendations
- **01-evidence-base/**: Research foundations, literature reviews, and evidence synthesis
- **02-curriculum/**: Educational framework, pedagogical approaches, and curriculum design
- **03-clinical-pathways/**: Care delivery models, clinical protocols, and pathway documentation
- **04-implementation/**: Practical deployment guides, change management, and adoption strategies
- **05-evaluation/**: Assessment frameworks, outcomes measurement, and evaluation tools
- **06-communications/**: Messaging strategies, stakeholder engagement, and dissemination plans
- **07-resources/**: Additional materials, references, and supporting documentation

## Contributing

When adding documentation:
- Place content in the appropriate subdirectory
- Use clear, descriptive filenames
- Include metadata (author, date, version)
- Follow markdown formatting standards
- Update this README if adding new sections
