# Research

Research protocols, data collection tools, analysis resources, and publications.

## Structure

- **protocols/**: Study protocols, research designs, and methodologies
- **data-collection/**: Data collection instruments, survey tools, and measurement frameworks
- **analysis-scripts/**: Statistical analysis code, data processing scripts, and analytical tools
- **publications/**: Published research, manuscripts, and presentation materials

## Using These Resources

### For Researchers
- Review existing protocols before designing new studies
- Use standardized data collection instruments
- Share analysis scripts and methods
- Contribute findings back to the community

### Research Ethics
- Obtain appropriate IRB/ethics approval
- Follow data protection and privacy regulations
- Maintain participant confidentiality
- Report findings transparently

## Contributing

Research contributions should:
- Include clear methodology
- Provide reproducible analysis code
- Document data sources and limitations
- Follow ethical research practices
- Share both positive and negative findings
