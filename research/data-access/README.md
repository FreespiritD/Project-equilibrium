# Data Access Policy

## Overview

Project EQUILIBRIUM is committed to responsible data sharing to advance research while protecting participant privacy and confidentiality.

## Types of Data

### 1. De-identified Aggregate Data
- Summary statistics
- Anonymized aggregated findings
- Published results

**Access**: Publicly available via repository

### 2. De-identified Individual-Level Data
- Student assessment data (de-identified)
- Patient outcome data (anonymized)
- Practice-level data

**Access**: By application, with data sharing agreement

### 3. Identifiable Data
- Raw clinical data with identifiers
- Student-linked assessment data

**Access**: Restricted, requires ethics approval and strong justification

## How to Request Data

### Step 1: Review Available Data

See [data catalog](#) for available datasets

### Step 2: Submit Request

Complete [data access application](#)

Include:
- Researcher details and qualifications
- Institutional affiliation
- Research question and justification
- Analysis plan
- Ethics approval (if required)
- Data security arrangements
- Publication plans

### Step 3: Review

- Data governance committee reviews (monthly)
- Decision within 4-6 weeks
- May request modifications or additional information

### Step 4: Agreement

If approved:
- Data sharing agreement signed
- Access credentials provided
- Training on data use (if required)

## Conditions of Access

**Researchers must:**
- Use data only for stated purpose
- Maintain confidentiality and security
- Not attempt re-identification
- Follow all ethics requirements
- Acknowledge EQUILIBRIUM in publications
- Share findings with EQUILIBRIUM team
- Destroy or return data when project complete

## Publication

**Researchers should:**
- Share draft manuscripts with EQUILIBRIUM team
- Acknowledge data source appropriately
- Offer co-authorship to data contributors (where appropriate)
- Submit final publications to EQUILIBRIUM repository

## Costs

- **Academic research**: No charge for data access
- **Commercial research**: Cost recovery charges apply
- **Data preparation**: May charge for extensive data preparation

## Timeline

- Application review: 4-6 weeks
- Data preparation: 2-8 weeks (depending on complexity)
- Access granted: Within 12 weeks of application
