# Clinical Tools

Evidence-based tools for clinical practice, patient care, and decision support.

## Structure

- **pathways/**: Clinical pathways and care protocols
- **assessment-tools/**: Patient assessment instruments and screening tools
- **patient-materials/**: Educational materials and resources for patients
- **decision-aids/**: Shared decision-making tools and patient decision aids
- **ehr-templates/**: Electronic health record templates, order sets, and documentation tools

## Using These Tools

### For Clinicians
- Review evidence base for each tool
- Adapt to local practice context and regulations
- Obtain necessary institutional approvals
- Document outcomes and provide feedback

### Important Notes
- These tools are for informational purposes and must be adapted to your specific clinical setting
- Obtain appropriate review and approval before clinical implementation
- Ensure compliance with local regulations and standards
- Maintain professional liability coverage

## Contributing

Clinical tools should:
- Be evidence-based with clear citations
- Include implementation guidance
- Specify target populations
- Note any limitations or contraindications
- Include version control and update dates
