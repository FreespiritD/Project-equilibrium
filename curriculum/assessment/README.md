# EQUILIBRIUM Assessment Framework

## Overview

Assessment drives learning. To ensure students master EQUILIBRIUM competencies, assessment must be:
- **Summative** (counts toward grades)
- **Comprehensive** (knowledge, skills, attitudes)
- **Progressive** (builds across all 4 years)
- **Valid** (measures what it claims to measure)
- **Reliable** (consistent results)

This framework provides blueprints, materials, and quality assurance processes for assessing EQUILIBRIUM learning outcomes.

## Assessment Philosophy

### Key Principles

1. **"What you assess is what students learn"**
   - If not assessed, students deprioritize
   - EQUILIBRIUM must be formally summatively assessed

2. **Miller's Pyramid** (competence levels):
   - **Knows**: Written exams (knowledge)
   - **Knows how**: Written exams (application)
   - **Shows how**: OSCEs (demonstrates in simulated setting)
   - **Does**: Workplace-based assessments (real patients)

3. **Blueprinting**: Ensure assessment covers all learning objectives

4. **Standard setting**: Pass marks determined by competence, not norm-referencing

5. **Feedback for learning**: Formative and summative feedback

## Assessment Methods

### 1. Written Examinations (Knowledge)

**Format**: MCQs and Short Answer Questions (SAQs)

**Content weight**:
- **Year 1**: 15% of exams = EQUILIBRIUM content
- **Year 2**: 15% of exams = EQUILIBRIUM content
- **Years 3-4**: Integrated into clinical exams

**Question bank**: `case-based-exams/` - 500+ MCQs, 100+ SAQs

### 2. OSCEs (Skills)

**Stations per year**:
- **Year 1**: 1-2 stations
- **Year 2**: 2 stations (intervention delivery, shared decision-making)
- **Year 4**: Graduation competency stations (must pass to graduate)

**Materials**: `osce-stations/` - Blueprints, marking sheets, examiner training

### 3. Workplace-Based Assessments (Clinical Performance)

**Types**: Mini-CEX, Case-Based Discussions, Direct Observation

**Requirements**: Minimum 4 EQUILIBRIUM-focused WBAs in Years 3-4

**Templates**: `practical-skills-assessments/`

### 4. Reflective Portfolio (Attitudes)

**Components**:
- Personal wellbeing reflections
- Case studies (biopsychosocial formulations)
- Prescribing log (10 lifestyle, 5 medication)
- Feedback compilation

**Assessment**: Pass/Fail, must pass to graduate

**Requirements**: `reflective-portfolios/`

## Graduation Competency Requirements

**Students CANNOT graduate without demonstrating**:
1. ✅ Holistic assessment
2. ✅ Lifestyle prescription
3. ✅ Brief psychological intervention
4. ✅ Shared decision-making
5. ✅ Guideline-concordant prescribing

## Quality Assurance

- Standard setting (Angoff method, borderline regression)
- Psychometric analysis (item analysis, reliability)
- Examiner training and calibration
- Annual evaluation and improvement
